📘 Assignment 3: Functions & Modules in Python
📌 Overview

This assignment demonstrates the use of functions and modules in Python.
It consists of two tasks:

Calculating factorial using a function (loop-based)
Performing mathematical operations using Python's built-in math module
🧮 Task 1: Factorial Using Function
🔹 Description

A Python function is created to calculate the factorial of a given number using a loop.

🔹 Features
Uses a for loop to compute factorial
Handles:
Positive integers
Negative input (with validation)
Invalid input (error handling using try-except)
🔹 Example
Input: 5  
Output: Factorial of 5 is: 120
🔢 Task 2: Math Module Operations
🔹 Description

This program uses Python's math module to perform:

Square root
Natural logarithm (log base e)
Sine (in radians)
🔹 Features
Takes user input
Uses built-in functions from math module
Displays results clearly
🔹 Example
Input: 25  
Output:
Square Root: 5.0  
Natural Logarithm: 3.2188758248682006  
Sine: -0.13235175009777303
